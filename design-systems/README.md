## Hur du importerar till v0
1. Gå till https://v0.app → Design Systems
2. Klicka + New eller Import your design system
3. Lägg till denna GitHub-repo som källa: PaddeFTW/kvalitetsplan-mall
4. Lägg gärna till index.html som exempel-app
5. Låt v0 bygga starter och godkänn
