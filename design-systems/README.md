# Design Systems – Quality Works / Kvalitetsplan

Fyra färdiga designsystem som du kan importera till **v0 Design Systems 2.0**.

## Filer

| Fil | Stil | Användning |
|-----|------|------------|
| `design-laser-dark.md` | Mörk + cyan laser | Huvudstil, futuristisk |
| `design-laser-light.md` | Ljus + cyan laser | Ljus variant |
| `design-business.md` | Vitt + professionell blå | ISO / affär |
| `design-neutral-minimal.md` | Gråvitt + sky blue | Lugn & minimal |

## Hur du importerar till v0

1. Gå till [v0.app](https://v0.app) → **Design Systems**
2. Klicka **+ New** / **Import your design system**
3. Lägg till denna GitHub-repo som källa:
   `PaddeFTW/kvalitetsplan-mall`
4. (Valfritt) Lägg till `index.html` som exempel-app
5. Låt v0 analysera och godkänn starter

## CSS-variabler

Alla system använder samma token-struktur (`--bg-primary`, `--accent-primary` osv.) så du enkelt kan byta tema.
