# Quality WorX – Plan-trion

Tre standalone webbappar för bygg:

| Fil | Produkt | Färg |
|-----|---------|------|
| `kvalitetsplan.html` | Kvalitetsplan | Blå |
| `miljoplan.html` | Miljöplan | Grön |
| `arbetsmiljoplan.html` | Arbetsmiljöplan | Amber |

## Funktioner

- Dashboard + formulär + PDF-export
- Egenkontroll-checklistor (12 punkter vardera)
- localStorage (sparar i webbläsaren)
- Riktig PDF via jsPDF (CDN)

## Användning

Öppna valfri HTML-fil i webbläsaren. Ingen server krävs.

## Vercel

Deploy mappen som static site. Root = denna mapp.  
Varje fil blir t.ex. `/kvalitetsplan.html`.

## Gumroad

Sälj som ZIP med de tre filerna + denna README.  
Köpare öppnar filerna lokalt eller hostar själva.

## Begränsning

Praktiska mallar. Ersätter inte juridisk rådgivning, AFS eller myndighetskrav.
